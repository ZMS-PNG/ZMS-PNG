# Pixel scene assets

The pixel artwork is based on [TheMysteriousGhost/pixel-profile](https://github.com/TheMysteriousGhost/pixel-profile), used under the MIT License.

Customized for ZMS-PNG with the dusk palette, cat character, profile title, and tagline. The generator's cloud color and sprite variable collision was corrected during generation.

`hero.svg` and `divider.svg` contain the animations. The corresponding `-static.svg` files preserve the artwork for visitors who prefer reduced motion.

The original copyright and full license are retained in `LICENSE-pixel-profile.txt` and in each SVG.
