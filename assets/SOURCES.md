# Pixel scene assets

The pixel artwork is based on [TheMysteriousGhost/pixel-profile](https://github.com/TheMysteriousGhost/pixel-profile), used under the MIT License.

Customized for ZMS-PNG with the dusk palette, cat character, profile title, and tagline. The generator's cloud color and sprite variable collision was corrected during generation.

`hero.svg` and `divider.svg` contain the animations. The corresponding `-static.svg` files preserve the artwork for visitors who prefer reduced motion.

The original copyright and full license are retained in `LICENSE-pixel-profile.txt` and in each SVG.

The activity, project and practice cards were drawn for this profile. Vaultide is shown as an illustrated notebook, MAPES as a role-to-report scene, and the practice area as a pixel exploration path. Their SVG animations include static alternatives for visitors who prefer reduced motion. Public activity comes from the GitHub GraphQL and REST APIs, with the retrieval time and raw public values in `github-stats.json`.

The activity rank follows the current-year commit formula in [anuraghazra/github-readme-stats](https://github.com/anuraghazra/github-readme-stats/blob/master/src/calculateRank.js). Its MIT License is retained in `LICENSE-github-readme-stats.txt`. The rank combines commits, pull requests, issues, reviews, stars and followers.
